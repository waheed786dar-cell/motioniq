# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x.x   | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in MotionIQ, please **do not** open a public GitHub issue.

Instead, report it privately by opening a [GitHub Security Advisory](../../security/advisories/new) on this repository.

We aim to respond within 72 hours and will credit responsible disclosures in the release notes unless you request otherwise.
